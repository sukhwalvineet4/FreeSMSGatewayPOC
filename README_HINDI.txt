📱 FREE MOBILE SIM SMS GATEWAY — यूजर सेटअप एवं उपयोग गाइड
=========================================================================

यह प्रोजेक्ट आपके एंड्रॉइड फोन के सिम कार्ड का उपयोग करके कंप्यूटर से मुफ़्त (₹0.00) में SMS भेजने का एक आसान गेटवे सिस्टम है।

-------------------------------------------------------------------------
📋 1. आवश्यकताएँ (Prerequisites):
-------------------------------------------------------------------------
1. कंप्यूटर/लैपटॉप (Windows OS)
2. Node.js इनस्टॉल होना चाहिए (डाउनलोड लिंक: https://nodejs.org)
3. कोई भी एंड्रॉइड मोबाइल फोन (Samsung, Vivo, Redmi, OnePlus, Realme आदि) + USB केबल

-------------------------------------------------------------------------
🚀 2. इनस्टॉल एवं चालू करने के आसान स्टेप्स (Setup Steps):
-------------------------------------------------------------------------
स्टेप 1: इस प्रोजेक्ट फ़ोल्डर (FreeSMSGatewayPOC) को अपने कंप्यूटर में रखें।
स्टेप 2: फ़ोल्डर के अंदर मौजूद "start_sms_gateway.bat" फाइल पर डबल-क्लिक करें।
         (यह अपने आप सर्वर चालू करके आपके ब्राउज़र में http://localhost:3000 खोल देगा)

-------------------------------------------------------------------------
📱 3. फोन कनेक्ट कैसे करें (Phone Connection):
-------------------------------------------------------------------------
1. अपने एंड्रॉइड फोन की Settings -> About Phone -> Build Number पर 7 बार क्लिक करके Developer Options ऑन करें।
2. Developer Options के अंदर "USB Debugging" को ON करें।
3. फोन को USB केबल के ज़रिए लैपटॉप से कनेक्ट करें।
4. वेबसाइट पर ऊपर का लेबल अपने आप हरा होकर आपके फोन का नाम दिखाने लगेगा!

-------------------------------------------------------------------------
✉️ 4. फ्री SMS कैसे भेजें (How to Send SMS):
-------------------------------------------------------------------------
1. वेबसाइट (http://localhost:3000) पर जाएँ।
2. "Recipient Mobile Number" में जिस नंबर पर मैसेज भेजना है वो लिखें (उदा: +918155858353)।
3. "Text Message Content" में अपना मैसेज टाइप करें।
4. "Dispatch Free SMS Now" बटन पर क्लिक करें!
5. मैसेज आपके फोन के सिम कार्ड से तुरंत मुफ्त में सेंड हो जाएगा!

=========================================================================
✅ सपोर्टेड फीचर्स:
- 100% फ्री सिम एसएमएस (₹0.00 खर्च)
- ऑटोमैटिक फोन डिटेक्शन (Zero Click Connection)
- API ऑटो-पोलिंग एवं 1-Time SMS प्रोटेक्शन (प्रत्येक यूजर लॉगिन पर केवल 1 बार SMS)
- सभी एंड्रॉइड फोन्स पर वर्किंग
=========================================================================

-------------------------------------------------------------------------
🤖 5. API ऑटो-पोलिंग एवं 1-Time SMS टेस्टिंग (API Integration Guide):
-------------------------------------------------------------------------
1. ऐप/वेबसाइट पर यूजर लॉगिन का डाटा ऑटोमैटिक SMS भेजने के लिए:
   - "Live API Endpoint / Queue JSON URL" वाले बॉक्स में API या Sample URL डालें:
     `http://localhost:3000/sms_queue.json`
2. "Sample URL 🔗" बटन दबाकर तुरंत टेस्ट URL लोड कर सकते हैं।
3. "Fetch & Send Now 🚀" दबाने पर यह API से नंबर और मैसेज लेकर तुरंत SMS सेंड कर देगा।
4. "Auto-Poll API Every 10 Seconds 🔄" ऑन करने पर हर 10 सेकंड में API चेक होगी।
5. 🔒 **1-Time SMS Guarantee**: जो यूजर एक बार मैसेज प्राप्त कर चुका है, उसे दोबारा मैसेज नहीं जाएगा (Deduplication Blocked).
6. अगर दोबारा टेस्टिंग के लिए पुराने इतिहास को साफ़ करना हो, तो "Reset Sent History" बटन दबाएँ।
